Mostly it exists because I wanted to write .NET and React instead of yet more Python,
and a personal site is the smallest excuse that still forces you to finish things.

The look is a CRT terminal because every review site looks the same otherwise, and
because a [tooltip content="Bottom bar, blinking cursor, F10 for setup. Try it."]shell prompt[/tooltip]
turned out to be a better navigation metaphor than a header ever was.

Things that work right now:

- a bottom bar you can walk like a filesystem
- English and 中文, switchable in [settings]SETUP[/settings]
- interactive markup inside the prose, which is what this sentence is demonstrating

Things that don't, yet:

1. searching
2. anything resembling a backend
3. most of the actual writing

主要是因为我想写点 .NET 和 React，而不是再写 Python。
个人网站大概是最小的、又能逼你把东西做完的借口。

做成 CRT 终端的样子，一是因为评论站长得都差不多，
二是因为[tooltip content="底栏、闪烁的光标、F10 打开设置。可以试试。"]命令行提示符[/tooltip]
意外地比 header 更适合当导航的隐喻。

现在能用的：

- 一条能像文件系统一样走的底栏
- 中英文切换，在 [settings]设置[/settings] 里
- 正文里的可交互标记，比如这句话本身

还不能用的：

1. 搜索
2. 任何像样的后端
3. 绝大部分正文
