# Why this site exists

Mostly because I want a place to express myself without anyone would care enough to find, and I'm kinda shy doing this since the last time I wrote something was probably in highschool. But as I kept trying to tell myself, get tf out of the comfort zone or you'll get nowhere.

The second reason is I wanted to learn .NET and C# (but ended up not having a backend at all) instead of being a stinky Python user for the rest of my days. But Claude-sama did all the heavy lifting for me. I'm not proud of this, and I'm still trying to keep up with all the code and setups. Not really into frontend coding as a whole, but hopefully I'll be able to design something as cool by myself.
