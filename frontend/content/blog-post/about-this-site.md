# Why this site exists

Mostly because I want a place to express myself somewhere noone would care enough to find. I'm a little bit shy doing this since the last time I wrote something was probably in highschool, and TikTok culture destroyed my barin and expressive ability. But I really want to do some personal project and a website seems to be the easier one.

The second reason is I wanted to learn .NET and C# (but ended up not having a backend at all) instead of being a stinky Python user for the rest of my days. But Claude-sama did all the heavy lifting for me, Opus 5 pretty much implemented every crazy idea I had. I'm not proud of this, and I'm still trying to keep up with all the code and setups. Not really into frontend coding as a whole, but hopefully I'll be able to design something as cool by myself.

# Why is it Cyberpunk themed

To be honest, my ideal choice would be something like the UI design of Heroes of Might and Magic III: The Shadow of Death. My English isn't advanced enough to describe that, so please join me in welcoming Mr. Claude Opus 5:

> A somber gothic-fantasy aesthetic built from aged bronze, dark gilt trim, carved stone relief and lacquered hardwood, assembled into strictly bilateral, heraldic frames with distinct ornamental corner pieces. A single upper-left light source is baked into the bitmaps, and heavy bevels and recesses give the interface the volume and tactility of a physical object. The palette is deliberately held in a low-saturation warm-earth range — ochre, burnt umber, olive, dark teal — so that map tiles and character art read as the only bright layer. Icons and portraits are literal miniature paintings rather than abstract glyphs, drawn in the heavy-contour, painterly tradition of 80s–90s fantasy paperback covers and tabletop roleplaying manuals. Compact, information-dense layouts combine with the pixel-level crispness and faint banding of a fixed resolution and indexed palette to make the interface feel less like a layer on the screen than an object inside the world.

(This used to be a quote from GPT-6 Astra but Claude Opus 5 was just simply better)

But since this would pretty much require a PhD in Art and I can't rely everything on LLM, pixelated Cyberpunk theme (inspired by [link=https://store.steampowered.com/app/447530/VA11_HallA_Cyberpunk_Bartender_Action/]Va-11 Hall-A![/link]) was my second best choice. This decision had the same reason behind the low-poly design of my undergraduate thesis (a Unreal Engine 4 3D survival game): Low performance cost and [tooltip content="Kinda weird gramatically, but what I mean is you can unify art assets from different sources by simply adjusting the granule size of the pixel"]easily unified style[/tooltip], an absolute safe option for indie developers. I also happened to came across a [link=https://github.com/mdombrov-33/vault66-crt-effect]CRT effect pack[/link], gave it a try and worked well (I did everything including the prototype by myself until this point lmao), so I kept designing the site with it.

# 为什么会有这个网站

主要是因为我想找个没人找得到的地方发泄一下表现欲.我这人挺羞于表达的,特别是考虑到我上次写能成文的正经文章可能还是高中,并且最近几年脑子又给短视频文化拿坏了,表达能力下降得我自己都能注意到.但是我又真的很想做点什么个人项目,想了想个人网站可能是最简单的一个.

次要原因是我想找个机会学一下C#和.NET,而不是一辈子都当个只会写Python的(虽然到现在也完全没用到后端).虽然说最后重活全是Claude大人干的,Opus 5差不多能够实现我所有的想法.虽然不是很想学习前端,但我也在尽力理解他都干了啥,但是希望有一天我也能自己做出这么炫的玩意来.

# 为什么是赛博朋克主题

说实话,如果让我选的话,我的第一选择应该会是英雄无敌3那种UI风格.我也不知道怎么描述,所以有请Claude Opus 5:

> 一种阴沉的哥特奇幻美学,以做旧青铜、暗金镶边、雕石浮雕与上漆深色硬木构成严格左右对称的纹章式画框,四角饰有独立的雕花构件。单一光源自左上方烘死在位图之中,厚重的倒角与内陷赋予界面实物般的体积感与触感。整体色调被刻意压在低饱和的暖土色区间——赭石、焦棕、橄榄绿、暗青——使地图与角色立绘成为画面中唯一的亮层。图标与肖像是一幅幅具象的微型插画而非抽象符号,笔法承自八九十年代奇幻小说封面与桌面角色扮演手册的重描边厚涂传统。紧凑而信息密集的版式,配合固定分辨率、索引调色板与抖动渐变所特有的像素级锐利与轻微色带,让界面读起来不像浮于屏幕之上的图层,而像世界之内的一件器物。

(我原来问的是GPT-6 Astra,但是Claude Opus 5的回答秒了)

但是可以预见的是这种风格非专业人士是很难做到的,这种事LLM也不可靠,所以我想了想用了我很喜欢的[link=https://store.steampowered.com/app/447530/VA11_HallA_Cyberpunk_Bartender_Action/]Va-11 Hall-A[/link]那种像素赛博朋克风格.这个决定和我本科毕设做UE4游戏的时候选的低多边形美术风格是基本上一样的理由:低性能消耗,风格容易统一,对于独立开发者来说基本不会错.刚好我在网上看到了一个[link=https://github.com/mdombrov-33/vault66-crt-effect]CRT显示器的前端效果包[/link],拿来试了一下发现效果真不错(到这里为止还是我自己写的哈哈),就基于这种风格往下做了.
